# fix: declare core HTTP and TLS product dependencies

Add `NIOHTTP1` and `NIOTLS` directly to `GRPCNIOTransportCore`, matching the modules already imported by its stream state machine and server connection handler. This adopts the two-entry correction proposed in [upstream PR #200](https://github.com/grpc/grpc-swift-nio-transport/pull/200).

Package lower bounds remain unchanged: grpc-swift-2 2.3.0, swift-nio 2.96.0, nio-http2 1.42.0, transport-services 1.20.0, nio-ssl 2.34.0, nio-extras 1.27.0, certificates 1.14.0 and asn1 1.0.0. The repository has no tracked root Package.resolved; later validation must retain the actual resolver output instead of inventing exact selected versions.

Existing fork custom-transport coverage and client enqueue-race implementation remain unchanged.
